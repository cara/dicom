# Drittanbieter-Komponenten

Die gebaute Anwendung (`dist/index.html`, `dicom-viewer.html`) enthält folgende Open-Source-Komponenten:

| Komponente | Lizenz | Quelle |
|---|---|---|
| dicom-parser | MIT | https://github.com/cornerstonejs/dicomParser |
| jpeg-lossless-decoder-js | MIT | https://github.com/rii-mango/JPEGLosslessDecoderJS |
| @cornerstonejs/codec-openjpeg (JS/WASM-Build) | MIT | https://github.com/cornerstonejs/codecs |
| OpenJPEG (im WASM-Build enthalten) | BSD-2-Clause | https://github.com/uclouvain/openjpeg |
| @cornerstonejs/codec-charls (JS/WASM-Build) | MIT | https://github.com/cornerstonejs/codecs |
| CharLS (im WASM-Build enthalten) | BSD-3-Clause | https://github.com/team-charls/charls |
| mp4-muxer | MIT | https://github.com/Vanilagy/mp4-muxer |
| fflate | MIT | https://github.com/101arrowz/fflate |

Die vollständigen Lizenztexte liegen den jeweiligen Paketen bei (`node_modules/<paket>/LICENSE`) bzw. sind unter den angegebenen Quellen abrufbar.
